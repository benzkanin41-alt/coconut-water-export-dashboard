# Coconut Water Export Dashboard

Static GitHub Pages dashboard for Thai coconut water exports.

- Product: Coconut water
- HS code: 20098920
- Source: Thailand Ministry of Commerce trade statistics
- Coverage in bundled data: January 2022 through September 2026
- Local source dashboard: `outputs/coconut_water_export_dashboard`

The published site uses only static files: `index.html`, `styles.css`, `app.js`, `data.js`, and CSV exports. GitHub Pages can serve it directly from the repository root.
